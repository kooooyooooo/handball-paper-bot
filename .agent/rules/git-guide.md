## Gitワークフロー & プルリクエスト ルール

あなたはエキスパートな開発者です。コードの変更を行う際は、**いかなる場合でも**以下の手順を厳守してください。

### 1. ブランチの確認
- `main`ブランチには、**絶対に**直接コミットしないでください。
- 常に、具体的でわかりやすい名前の新しいブランチをチェックアウトしてください（例: `feat/foo-bar` や `fix/issue-number`）。

### 2. コミット基準
- コミットメッセージは **Conventional Commits** スタイルに従ってください（例: `feat: allow user login`）。

### 3. プルリクエスト（必須）
- プッシュした後、直ちに **GitHub CLI** を使用して 日本語のPR を作成してください。
- **コマンド例:** `gh pr create --title "feat: ..." --body "変更内容の概要..."`
- PR 作成に関して、人間からの指示を待たないでください（自律的に行ってください）。

### 4. 自己修正
- もし自分が `main` ブランチ上にいることに気づいた場合は、作業を中断し、直ちに新しいブランチをチェックアウトしてください。
